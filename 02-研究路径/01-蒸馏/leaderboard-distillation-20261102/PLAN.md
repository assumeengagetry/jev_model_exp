# 榜单决策模型蒸馏方法调研

## 范围

核查 Decision Index 可取得的最新榜单快照、作者模型卡、技术报告与公开训练代码。区分完整候选概率蒸馏、教师生成／标注数据、多教师评审、基础模型保留正则和推理链蒸馏，不因同一家族或名称相近混用版本结论。

本轮只做公开资料研究，不连接集群，不改变现有训练、标注或下载任务。

## 清单

- [x] 获取榜单当前可得快照与精确模型入口。
- [x] 核对代表模型的 Teacher、监督目标、损失、温度与质量控制。
- [x] 区分明确披露、代码可确认和未披露内容，复核版本及效果口径。
- [x] 汇总常用做法与当前 0.6B 候选匹配方案的适用关系，保存可追溯报告。

## 验证范围

主会话另行读取并核对 Perplexity、Bobcat、Sieve、Mapika、StartLux、Mammoth、Vela 和 Crivo 的关键原文／loss 代码，再集成独立研究结果。Teacher 身份、温度与 gold 冲突规则均按具体版本分别登记；没有以训练配置推断未公开的 Teacher，也没有把模型总分或不同代际分差当作纯 KD 增益。

未连接集群、未下载大权重、未安装依赖、未运行模型或实验。
