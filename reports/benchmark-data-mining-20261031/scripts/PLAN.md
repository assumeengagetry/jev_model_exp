# Decision Index 全榜数据画像

**目标：**逐项统计公开 benchmark 的真实输入长度、标签与正负比例、候选负担、数据重复与关联结构，以及影响模型表现的数据特征，形成易读中文报告与图表。

**执行方式：**在 sh-09-gpu 复用已落盘公开 suite、现有 Python 环境和 Qwen3 tokenizer；只做 CPU 数据分析。所有新增脚本、明细和图表写入本轮独立目录，不修改现有训练配置、数据、模型或进程。

## 工作清单

- [ ] 找回榜单、确认公开 benchmark 范围及实际可用数据。
- [ ] 明确请求、问题、候选匹配对和关联组的统计口径。
- [ ] 全量扫描：样本数、题数、token 长度分位数、长度分桶、上下文覆盖率。
- [ ] 全量扫描：原生标签分布、noul 真/假比例、choice 正负匹配比例、score 等级分布。
- [ ] 补充候选数、题数/请求、重复 state、关联组、选项位置、文本结构与长度—标签关联。
- [ ] 绘制长度/覆盖率热力图、标签与候选结构图、五维雷达图及计算负担对比。
- [ ] 编写逐 benchmark 中文分析、总体发现、数据与训练配置建议；标注实际数据范围。
- [ ] 阅读生成的统计和图表，核对汇总口径，交付报告、浏览版和两位小数明细。

## 展示约定

- 数字最多两位小数；大数使用约数和“万/亿”，CSV 保留整数计数。
- 不把“情感正负”“判断真/假”“候选匹配/不匹配”当作同一种标签。
- 公开原始请求实测与推导量分开；不把训练池、静态统计或相关关系写成模型效果实验。
- 不增加模型训练、模型推理或工程测试；不自动提交，不改动其他会话产物。
- 主报告不列任何哈希，不写安全或测试章节。

## 产物

- `REPORT.md`：结论、逐项表格和数据解释。
- `index.html`：中文图文浏览版。
- `figures/`：PNG 与 SVG 图表。
- `tables/`：逐 benchmark、逐领域、长度分桶、标签分布等 CSV。
- `scripts/`：本轮数据统计和图表生成脚本。
- `summary.json`：不超过两位小数的汇总。
